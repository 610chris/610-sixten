シーホース三河から2選手、 「B.LEAGUE ALL-STAR GAME WEEKEND 2027」出場決定 —— 須田侑太郎はTOKAI-KANSAI UNITEDキャプテンに

2026.11.20 — 610 BASKETBALL JOURNAL

シーホース三河は、須田侑太郎選手(#13)と西田優大選手(#19)の2選手が「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」(2027年1月15日(金)~17日(日)、愛知県名古屋市のIGアリーナ)への出場が決定したと11月20日発表した。

須田侑太郎はTOKAI-KANSAI UNITEDのキャプテンに

須田侑太郎選手は、1月15日(金)に行われる「SPORTS DEPO B.LEAGUE ALL-STAR ASIA CROSS TOURNAMENT 2027」で、TOKAI-KANSAI UNITEDのキャプテンとして出場することが決定した。オールスター登録背番号は「#13」。

西田優大はB.BLACKのスターティング5に選出

西田優大選手は、1月17日(日)に行われる「りそなグループ B.LEAGUE ALL-STAR GAME 2027」で、B.BLACKチームのスターティング5に選出された。オールスター登録背番号は「#19」。

来年1月、名古屋IGアリーナでオールスターウィークエンド

「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」は、公益財団法人日本バスケットボール協会と公益社団法人ジャパン・プロフェッショナル・バスケットボールリーグの主催、B.LEAGUEの主管で開催される。会期中には「スポーツくじ DUNK DUNK CONTEST」「OJI GROUP 3POINT CONTEST」「SHISEIDO MEN SKILLS CHALLENGE」「インフロニア B.LEAGUE U18 ALL-STAR GAME 2027」「マスコット大運動会 2027」といった関連企画も予定されている。
