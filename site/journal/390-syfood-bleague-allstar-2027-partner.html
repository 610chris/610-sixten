「世界の山ちゃん」のエスワイフード、 B.LEAGUE ALL-STAR GAME WEEKEND 2027に イベントパートナー就任 —— 来年1月、名古屋IGアリーナで開催

2026.10.09 — 610 BASKETBALL JOURNAL

「世界の山ちゃん」を国内外で約90店舗展開する株式会社エスワイフード（愛知県名古屋市、代表取締役：山本久美）は10月9日、公益社団法人ジャパン・プロフェッショナルバスケットボールリーグ（B.LEAGUE、東京都文京区、コミッショナー：島田慎二）が2027年1月15日（金）から17日（日）にかけて愛知県名古屋市のIGアリーナで開催する「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」のB.LEAGUE EVENT PARTNERSに就任したと発表した。

テーマは「熱狂×革新=未来」、ロゴは金の鯱

「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」は、国内男子バスケットボールの祭典として名古屋のIGアリーナで開催される。テーマは「熱狂×革新=未来」で、イベントロゴは愛知・名古屋を象徴する「金の鯱」をメインにデザインされている。バスケットボールと街の文化を融合させ、スポーツエンターテインメントの新たな形を目指すとしている。

地元・愛知の企業として大会を盛り上げる

エスワイフードは本社を名古屋市に置く地元企業で、今回のイベントパートナー就任にあたり「地元・愛知、名古屋に根差す企業として、地域の皆さまとともに本イベントを一層盛り上げてまいります」とコメントしている。具体的な取り組みの内容は今後順次発表するという。

「幻の手羽先」の世界の山ちゃんとは

エスワイフードが運営する「世界の山ちゃん」は、名物の「幻の手羽先」を看板商品とする居酒屋チェーンで、国内外で90店舗を展開する。やみつきになる辛さと風味が特徴の独自の「幻のコショウ」が味の決め手になっているという。名古屋発の飲食ブランドが、同じ名古屋で開催される国内最大規模のバスケットボールイベントを支える形になる。

610の視点

B.LEAGUE ALL-STAR GAME WEEKENDのような大型イベントでは、開催地の地元企業がパートナーに名を連ねるケースが目立つ。今回も、名古屋を本拠とする飲食チェーンが開催都市での存在感を高める狙いが読み取れる。具体的な企画内容は「今後順次発表」とされており、会場での展開や協業企画がどう具体化していくかが注目される。
