610（シックステン）とは？

バスケットボールとカルチャーの交差点からブランドの物語をつくる日本（東京）のメディアエージェンシーです。本ジャーナルのほか、動画メディア「クリスのバスケ日記」、トーク番組「POST UP PODCAST」を運営しています。

どんなバスケのニュースを扱っている？

NBAのトレード・契約・引退などの速報（Shams Charania（ESPN）ら一次ソースを明記）、Bリーグ・日本代表・ユース・スクールなど国内バスケの話題、バッシュやスニーカー、バスケにまつわるカルチャー。カテゴリは NBA / JAPAN / KICKS / CULTURE / REPORT の5つです。

記事の情報源は？

すべての記事の末尾に出典（プレスリリース、報道、記者のXポストなど）のURLを明記しています。一次ソースに書かれていない事実は足さない方針で編集しています。

更新頻度は？
