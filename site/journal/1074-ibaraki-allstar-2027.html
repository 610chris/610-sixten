茨城ロボッツから3選手、 B.LEAGUE ALL-STAR GAME 2027出場決定 —— 吉井裕鷹はヴィック・ロー離脱でスターティング5へ

2026.11.19 — 610 BASKETBALL JOURNAL

茨城ロボッツは、吉井裕鷹選手(#8)・レイ・パークスジュニア選手(#1)・赤間賢人選手(#12)の3選手が「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」(2027年1月15日(金)~17日(日)、愛知県名古屋市のIGアリーナ)への出場が決定したと11月19日発表した。

吉井裕鷹はヴィック・ロー離脱でスターティング5に繰り上がり

吉井裕鷹選手は「りそなグループ B.LEAGUE ALL-STAR GAME 2027」のB.BLACKチームに選出された。当初選出されていた#4ヴィック・ロー選手が、既に発表されている負傷のため出場を辞退することになり、これに伴い吉井選手がスターティング5に繰り上がって選出された。今大会のオールスター登録背番号は「#91」。

パークスジュニアと赤間はASIA CROSS TOURNAMENTへ

レイ・パークスジュニア選手は「SPORTS DEPO B.LEAGUE ALL-STAR ASIA CROSS TOURNAMENT 2027」のASIA ALL-STARSに選出され、オールスター登録背番号は「#1」。赤間賢人選手は同大会のRISING STARSに選出され、オールスター登録背番号は「#13」となる。

来年1月、名古屋IGアリーナでオールスターウィークエンド

「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」は、公益財団法人日本バスケットボール協会と公益社団法人ジャパン・プロフェッショナル・バスケットボールリーグの主催、B.LEAGUEの主管で開催される。会期中には「スポーツくじ DUNK DUNK CONTEST」「OJI GROUP 3POINT CONTEST」「SHISEIDO MEN SKILLS CHALLENGE」「インフロニア B.LEAGUE U18 ALL-STAR GAME 2027」「マスコット大運動会 2027」といった関連企画も予定されている。チケットは12月1日(火)に名古屋ダイヤモンドドルフィンズのファンクラブ会員先行販売、12月2日(水)にB.LEAGUEチケット販売が開始される。
