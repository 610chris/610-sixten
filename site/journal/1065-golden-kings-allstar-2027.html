琉球ゴールデンキングスから4選手、「B.LEAGUE ALL-STAR GAME WEEKEND 2027」出場決定 —— クーリー・ラベナ、U18は宮里とマクミラン

2026.11.19 — 610 BASKETBALL JOURNAL

沖縄バスケットボール株式会社（琉球ゴールデンキングス）は11月19日、2027年1月15日（金）〜17日（日）に愛知県名古屋市のIGアリーナで開催される「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」に、トップチームから2選手、U18から2選手、合わせて4選手の出場が決定したと発表した。

トップチームはクーリーとラベナ

#45 ジャック・クーリー（Jack Cooley）選手は1月17日（日）の「りそなグループ B.LEAGUE ALL-STAR GAME 2027」に、チーム「B.WHITE」の一員として出場する。#11 キーファー・ラベナ（Kiefer Ravena）選手は1月15日（金）の「SPORTS DEPO B.LEAGUE ALL-STAR ASIA CROSS TOURNAMENT 2027」に、アジア各国の代表選手が集う「ASIA ALL-STARS」の一員として出場する。

U18は宮里俊佑とマクミラン ジェイデン、宮里は3ポイントコンテストにも

1月16日（土）の「インフロニア B.LEAGUE U18 ALL-STAR GAME 2027」には、キングスU18から宮里俊佑選手（チーム「HELIOS」）とマクミラン ジェイデン選手（チーム「JADE」）が出場する。宮里選手は同日に行われる「王子グループ スリーポイントコンテスト」にも出場予定で、U18世代の代表として2つの舞台に立つ。

610の視点

琉球ゴールデンキングスは昨季Bリーグを代表する強豪の一角で、フィリピン代表のエースガードであるラベナと、インサイドを支えるビッグマンのクーリーという、異なるタイプの2人がそろって選出された形だ。トップチームだけでなくU18からも2選手が選ばれたことは、沖縄のバスケットボール育成が着実にトップレベルへつながっていることを示しているとみられる。2027年1月の名古屋には、沖縄発の4選手の活躍に注目したい。
