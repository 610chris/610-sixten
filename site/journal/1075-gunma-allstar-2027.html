群馬クレインサンダーズから4選手、 B.LEAGUE ALL-STAR GAME WEEKEND 2027出場決定 —— スタンリー・ジョンソンはファン投票で初選出

2026.11.19 — 610 BASKETBALL JOURNAL

群馬クレインサンダーズは、スタンリー・ジョンソン選手(#14)・エージェー・エドゥ選手(#15)・淺野ケニー選手(#16)・細川一輝選手(#29)の4選手が「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」(2027年1月15日(金)~17日(日)、愛知県名古屋市のIGアリーナ)への出場が決定したと11月19日発表した。

ジョンソンはファン投票でB.WHITEに初選出

スタンリー・ジョンソン選手は、ファンの投票により「りそなグループ B.LEAGUE ALL-STAR GAME 2027」のB.WHITEチームに初めて選出された。同ゲームは大会第3日、2027年1月17日(日)に行われる。かつてNBAでプレーしたジョンソン選手は、今シーズンから群馬でプレーしている。

エドゥは3大会連続3回目、淺野と細川は初選出

エージェー・エドゥ選手は「SPORTS DEPO B.LEAGUE ALL-STAR ASIA CROSS TOURNAMENT 2027」のASIA ALL-STARSに選出された。3大会連続3回目の選出で、大会第1日の2027年1月15日(金)に出場する。同じ第1日に行われるRISING STARSには淺野ケニー選手が初めて選出された。

細川一輝選手は、大会第2日の2027年1月16日(土)に行われる「OJI GROUP 3POINT CONTEST」に初選出された。

来年1月、名古屋IGアリーナでオールスターウィークエンド

「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」は、公益財団法人日本バスケットボール協会と公益社団法人ジャパン・プロフェッショナル・バスケットボールリーグの主催、B.LEAGUEの主管で開催される。会期中には「スポーツくじ DUNK DUNK CONTEST」「OJI GROUP 3POINT CONTEST」「SHISEIDO MEN SKILLS CHALLENGE」「インフロニア B.LEAGUE U18 ALL-STAR GAME 2027」「マスコット大運動会 2027」といった関連企画も予定されている。
