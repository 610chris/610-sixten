「B.LEAGUE ALL-STAR GAME WEEKEND 2027」出場選手発表会見を11月19日にライブ配信 —— 愛知・名古屋で来年1月開催

2026.11.18 — 610 BASKETBALL JOURNAL

スポーツナビ株式会社は11月19日(木)11:00から、2027年1月に愛知県名古屋市で開催される「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」の出場選手発表会見をライブ配信する。

会見では全コンテンツの出場選手が発表、視聴はスポーツナビで

出場選手発表会見では、ファン投票とB.LEAGUE推薦によって選出された選手が対戦する「りそなグループ B.LEAGUE ALL-STAR GAME 2027」のほか、アジアの選手たちが参加する「SPORTS DEPO B.LEAGUE ALL-STAR ASIA CROSS TOURNAMENT 2027」、各種コンテスト、「インフロニア B.LEAGUE U18 ALL-STAR GAME 2027」など、全コンテンツの出場選手が発表される。視聴はPC版・スマートフォンブラウザ版の「スポーツナビ」、および「スポーツナビ」アプリ(iOS版・Android版)で無料。会見にはこにわ氏(MC)・今井麻椰氏らに加え、名古屋ダイヤモンドドルフィンズから選手2名が登壇し、ドルチィ・りそにゃ・白戸家のお父さん・ドアラの4体のマスコットも参加する。

開催は2027年1月15日〜17日、愛知・名古屋で「バスケと街の夢の共演」

「りそなグループ B.LEAGUE ALL-STAR GAME WEEKEND 2027 IN AICHI-NAGOYA」は「バスケと街の夢の共演」をコンセプトに、2027年1月15日(金)から17日(日)の3日間、愛知県名古屋市で開催されるオールスターイベント。「りそなグループ B.LEAGUE ALL-STAR GAME 2027」の出場選手を選ぶファン投票は既に始まっており、公式デジタルトレーディングカードサービス『B.LEAGUE CARD』で投票できる。

610の視点

開催地の名古屋では本拠地の名古屋ダイヤモンドドルフィンズが開幕から好調を続けており、地元開催のオールスターへの地ならしとしても会見の注目度は高いとみられる。ファン投票で選ばれる選手に加えて「B.LEAGUE推薦」枠が誰に当たるかも発表の見どころで、11月19日の会見を経て『B.LEAGUE CARD』での投票はさらに加速しそうだ。
